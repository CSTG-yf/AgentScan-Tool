# 异常检测设置 API 设计

日期：2026-09-05

## API 前缀

建议使用独立前缀：

```http
/api/v1/runtime-detection-settings
```

原因：

- `/api/v1/runtime-detections` 已用于异常事件列表和详情。
- `/api/v1/agent-governance` 当前主要用于 AgentType、静态资源规则、扫描方案、静态风险解释。
- 异常检测设置会影响 runtime detection、runtime decision、attack chain，语义上应独立成域。

如需保持页面归属，也可以在前端把页面放入“Agent 治理中心”，但 API 不必放进 `agent-governance` 前缀。

## 通用约定

### 分页参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `page` | integer | 可选，默认 1 |
| `page_size` / `pageSize` | integer | 可选，默认 20，最大 200 |
| `keyword` | string | 可选，模糊查询 |
| `enabled` | boolean/string | 可选，`true` / `false` / `all` |

### 时间字段

所有时间字段使用 RFC3339 字符串。

### 删除策略

所有删除接口建议软删除：

```json
{
  "deleted": true
}
```

内置规则不允许物理删除。对内置规则执行 DELETE 时，后端可以实现为：

- `enabled=false`
- `hidden=true`
- 或返回 409，要求前端使用禁用操作

推荐第一种：删除内置规则等价于隐藏/禁用。

### 决策值

后端使用现有 runtime decision 枚举：

| 前端展示 | 后端值 |
| --- | --- |
| ALLOW | `ALLOW` |
| ALERT | `ALERT` |
| ASK | `CONFIRM` |
| BLOCK | `BLOCK` |

## 1. 页面总览

### 查询异常检测设置总览

```http
GET /api/v1/runtime-detection-settings/overview
```

返回：

```json
{
  "global_rule_count": 12,
  "enabled_global_rule_count": 10,
  "agent_type_count": 7,
  "custom_agent_type_count": 3,
  "blacklist_count": 16,
  "custom_risk_policy_count": 2,
  "updated_at": "2026-09-05T10:00:00Z"
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `global_rule_count` | 通用异常检测规则总数 |
| `enabled_global_rule_count` | 已启用通用规则数 |
| `agent_type_count` | AgentType 总数 |
| `custom_agent_type_count` | 有专属配置的 AgentType 数 |
| `blacklist_count` | 黑名单总数 |
| `custom_risk_policy_count` | 自定义风险策略数量 |

## 2. 通用异常检测规则

### 查询通用异常检测规则

```http
GET /api/v1/runtime-detection-settings/rules?scope=global&page=1&page_size=20&keyword=&enabled=all
```

查询参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `scope` | string | 固定传 `global` 查询通用规则 |
| `keyword` | string | 匹配 rule_id、rule_name、detection_type、category |
| `enabled` | string | `true` / `false` / `all` |
| `source` | string | 可选，`builtin` / `custom` |

返回：

```json
{
  "items": [
    {
      "id": 1,
      "rule_id": "prompt_injection",
      "rule_name": "Prompt Injection",
      "source": "builtin",
      "scope": "global",
      "agent_type_id": null,
      "detection_type": "prompt_injection",
      "category": "attack",
      "severity": "HIGH",
      "confidence": 0.9,
      "matcher": {
        "kind": "builtin",
        "builtin_rule_id": "prompt_injection"
      },
      "detail": "Detect prompt injection patterns in prompts and tool inputs.",
      "remediation": "Review prompt source and block unsafe instruction override.",
      "priority": 100,
      "enabled": true,
      "system": true,
      "version": 1,
      "created_at": "2026-09-05T10:00:00Z",
      "updated_at": "2026-09-05T10:00:00Z"
    }
  ],
  "total": 1,
  "page": 1,
  "page_size": 20
}
```

### 新增通用异常检测规则

```http
POST /api/v1/runtime-detection-settings/rules
```

请求：

```json
{
  "scope": "global",
  "rule_id": "custom_tool_to_external_domain",
  "rule_name": "Tool External Domain Access",
  "detection_type": "untrusted_network_access",
  "category": "attack",
  "severity": "HIGH",
  "confidence": 0.85,
  "matcher": {
    "kind": "event_match",
    "event_category": "network",
    "target": {
      "match_type": "regex",
      "value": "https?://.*"
    },
    "tool_name": {
      "match_type": "contains",
      "value": "fetch"
    }
  },
  "detail": "Tool accessed an external domain.",
  "remediation": "Review the target domain and tool invocation.",
  "priority": 120,
  "enabled": true
}
```

返回：创建后的规则对象。

### 修改通用异常检测规则

```http
PATCH /api/v1/runtime-detection-settings/rules/{id}
```

请求：

```json
{
  "rule_name": "Tool External Network Access",
  "severity": "CRITICAL",
  "confidence": 0.9,
  "enabled": true,
  "priority": 80
}
```

说明：

- `custom` 规则允许修改全部字段。
- `builtin` 规则建议只允许修改 `enabled`、`severity`、`confidence`、`priority`、`detail`、`remediation`。
- 修改后应更新 `version`。

### 删除通用异常检测规则

```http
DELETE /api/v1/runtime-detection-settings/rules/{id}
```

返回：

```json
{
  "id": 1,
  "deleted": true
}
```

### 保存 AgentType 自定义风险策略

```http
PUT /api/v1/runtime-detection-settings/agent-types/{agent_type_id}/risk-policy
```

请求：

```json
{
  "use_global_risk_policy": false,
  "policy": {
    "name": "CLI Agent Runtime Risk Policy",
    "rules": [
      {
        "risk_level": "LOW",
        "min_score": 0,
        "max_score": 0.29,
        "decision": "ALLOW",
        "enabled": true
      },
      {
        "risk_level": "MEDIUM",
        "min_score": 0.3,
        "max_score": 0.59,
        "decision": "ALERT",
        "enabled": true
      },
      {
        "risk_level": "HIGH",
        "min_score": 0.6,
        "max_score": 0.84,
        "decision": "CONFIRM",
        "display_decision": "ASK",
        "enabled": true
      },
      {
        "risk_level": "CRITICAL",
        "min_score": 0.85,
        "max_score": 1,
        "decision": "BLOCK",
        "enabled": true
      }
    ]
  }
}
```

校验规则：

- 分值范围必须覆盖 `0.0 - 1.0`。
- 区间不能交叉。
- `min_score <= max_score`。
- `decision` 必须是 `ALLOW`、`ALERT`、`CONFIRM`、`BLOCK` 之一。
- 前端传 `ASK` 时，后端应转换为 `CONFIRM` 或返回明确错误。

### 切回通用风险策略

```http
PUT /api/v1/runtime-detection-settings/agent-types/{agent_type_id}/risk-policy
```

请求：

```json
{
  "use_global_risk_policy": true
}
```

返回：当前 AgentType 详情配置。

## 10. 保存后的变化通知

任何异常检测设置变更后，后端应写入 change domain：

```text
runtime_detection_settings
```

如果变更会影响检测结果，也建议同时写入：

```text
scan_jobs
runtime_detections
runtime_decisions
runtime_attack_chains
```

但注意：规则保存本身不应自动重放历史事件。历史重算仍由用户显式创建 Job。

前端刷新：

```http
GET /api/v1/changes?cursor=123&domains=runtime_detection_settings,scan_jobs
```

## 11. 与 Job 接口的配合

规则保存后，如果用户点击“应用到历史数据”，前端调用：

```http
POST /api/v1/jobs
```

请求示例：

```json
{
  "kind": "event_replay",
  "trigger": "manual",
  "scope": {
    "agent_type_id": 1,
    "reason": "runtime_detection_settings_changed"
  },
  "idempotency_key": "runtime-settings-replay-agent-type-1-20260905"
}
```

如果只重放通用规则影响范围：

```json
{
  "kind": "event_replay",
  "trigger": "manual",
  "scope": {
    "reason": "global_runtime_detection_rules_changed"
  }
}
```

## 12. 错误码建议

| 状态码 | 场景 |
| --- | --- |
| 400 | 参数错误、matcher JSON 不合法、风险分值区间不合法 |
| 404 | AgentType、规则、黑名单或策略不存在 |
| 409 | 内置规则不允许删除、规则 ID 冲突、风险区间冲突 |
| 422 | 正则过于复杂、规则无法编译、策略缺少必要等级 |
| 500 | 数据库或内部执行错误 |

## 13. 前端调用顺序

页面首次进入：

```text
GET /overview
GET /rules?scope=global

GET /agent-types
```

```text

```

保存基础设置：

```text
PATCH /agent-types/{agent_type_id}/settings

GET /agent-types
```

新增专属规则：

```text
POST /agent-types/{agent_type_id}/rules
GET /agent-types/{agent_type_id}
GET /agent-types
```

新增黑名单：

```text
POST /agent-types/{agent_type_id}/blacklist
GET /agent-types/{agent_type_id}
GET /agent-types
```

保存自定义风险策略：

```text
PUT /agent-types/{agent_type_id}/risk-policy
GET /agent-types/{agent_type_id}
```

应用到历史数据：

```text
POST /api/v1/jobs kind=event_replay

```
